## About Me

Senior software developer and consultant with **30+ years of experience** building, taking over, modernizing and supporting business-critical software.

I have been using **SoftVelocity Clarion since the Clarion Professional Developer (CPD) era (30+ years)**, through later DOS and Windows releases, Legacy and ABC applications, and current Clarion development.

A large part of my consulting work involves **taking over existing Clarion applications** when the original developer has retired, moved on or is no longer available.

That work often includes:

- Understanding existing source code and business logic
- Rebuilding or restoring dependable development environments
- Clarion Legacy and ABC applications
- Troubleshooting difficult or long-standing problems
- Continuing and completing existing development
- Application modernization and version migration
- Microsoft SQL Server integration
- TPS / DAT and other data conversions
- Reporting and workflow improvements
- Web services and REST API integration
- Long-term development and support
